# GAMEHUB pour Android

Des mini-jeux rapides à plusieurs, des défis, des groupes et des championnats entre amis.

## Télécharger

**https://gamehub-kaeloo.onrender.com/telecharger**

Ou directement le fichier : [gamehub-android.apk](https://github.com/Epaphrodi3te/gamehub-app/releases/latest/download/gamehub-android.apk) (tous les téléphones Android).

## Installer

1. Télécharge le fichier.
2. Ouvre-le ; si Android le demande, autorise ton navigateur à installer des applications.
3. Installe, ouvre GAMEHUB et connecte-toi.

Android peut afficher un avertissement car l’app n’est pas encore sur le Play Store : c’est normal. Ensuite, l’app se met à jour toute seule.

Sur iPhone : joue directement sur https://gamehub-kaeloo.onrender.com (Partager → « Sur l’écran d’accueil »).
